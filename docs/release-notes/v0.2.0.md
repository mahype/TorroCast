TorroCast from outside, and a Mac download that opens without a detour.

**From outside.** `torrocast daemon` plays without a window, `torrocast status` says as JSON
what plays, what waits in Up Next and what is new, `torrocast ctl play|pause|next|…` steers it —
the makings of a desktop widget. One TorroCast plays at a time: the terminal interface takes
over from a running daemon and goes on where it was; a second interface is refused. There is a
widget for Omarchy's bar already: [omarchy-torrocast](https://github.com/mahype/omarchy-torrocast).
See [docs/fernsteuerung.md](https://github.com/mahype/TorroCast/blob/main/docs/fernsteuerung.md).

**Signed and notarized on macOS.** The Mac binary now carries a Developer ID signature and
Apple's notarization; Gatekeeper lets it start without `xattr`.

**Search** marks the shows you have subscribed to already.

## Downloads

| System | File |
| --- | --- |
| macOS, Apple Silicon and Intel | `torrocast-0.2.0-macos-universal.tar.gz` |
| Windows, x86-64 | `torrocast-0.2.0-windows-x86_64.zip` |
| Linux, x86-64 | `torrocast-0.2.0-linux-x86_64.tar.gz` |

Each archive has its checksum beside it (`.sha256`); `SHA256SUMS` lists all three.
Unpack, then start `torrocast` in a terminal of at least 80 × 24. `?` lists every key.

- **macOS:** put `torrocast` somewhere on your `PATH`, e.g. `/usr/local/bin`.
- **Windows:** run it in Windows Terminal. `daemon`, `status` and `ctl` are not there yet on
  Windows; `status` always says `running: false`.
- **Linux** needs ALSA (`alsa-lib` / `libasound2`); PipeWire and PulseAudio are reached through it.

Media keys work on Linux (MPRIS) for now.
