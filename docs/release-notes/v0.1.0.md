The first release of TorroCast: a podcast player for the terminal.

**Find.** Search Apple's podcast directory for shows or single episodes, browse charts and
categories by country. fyyd and Podcast Index can be switched on in Settings; Podcast Index
wants your own free key.

**Read.** Show notes laid out for the terminal with numbered links, and chapters from all three
places they can live — the feed, the `podcast:chapters` file and the ID3 tag of the MP3.

**Listen.** Streaming playback with tempo at the same pitch, chapter jumps, a sleep timer, an
Up Next queue after the model of Pocket Casts, your own playlists, downloads for the road.
MP3, AAC, Opus, Vorbis, FLAC.

**Keep.** Subscriptions, Up Next and playback positions live in a library folder of your
choice. Put it into Dropbox, Syncthing or onto a NAS and every device shares it. OPML in and out.

## Downloads

| System | File |
| --- | --- |
| Linux, x86-64 | `torrocast-0.1.0-linux-x86_64.tar.gz` |
| macOS, Apple Silicon and Intel | `torrocast-0.1.0-macos-universal.tar.gz` |
| Windows, x86-64 | `torrocast-0.1.0-windows-x86_64.zip` |

Unpack, then start `torrocast` in a terminal of at least 80 × 24. `?` lists every key.

- **Linux** needs ALSA (`alsa-lib` / `libasound2`); PipeWire and PulseAudio are reached through it.
- **macOS:** the binary is not notarized. If Gatekeeper holds it back:
  `xattr -d com.apple.quarantine torrocast`
- **Windows:** run it in Windows Terminal.

Media keys work on Linux (MPRIS) for now. The interface speaks German or English, following the
system's language.
